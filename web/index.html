Every allow / block decision is logged by the contract. A blocked spend still costs gas (it is a real transaction) but moves no funds.

How it works

  1. Owner sets a policy on-chain: max per transaction, daily budget, receiver allowlist, and a pause switch.
  2. The agent gets a function-call key scoped to spend() only — it can never withdraw, change the policy, or move funds any other way.
  3. Every spend is checked by the contract: paused? over max/tx? over daily budget? receiver allowlisted? Each check that fails blocks the spend.
  4. Every decision is logged on-chain with the reason, so the owner can audit exactly what the agent tried to do.
